## 1. 外观与主题

### 多主题切换

- **8 套主题色**：靛蓝、海蓝、薄荷、森绿、琥珀、玫红、紫罗兰、石墨
- **亮色 / 暗色 / 跟随系统** 三种模式，两者自由组合 —— 共 16 种外观
- 主题色不只改按钮颜色：**整个界面的中性灰阶都会跟着色相走**，所以「薄荷」主题
  的深灰会偏一点点绿，视觉上是一整套而不是「换了强调色的同一套皮肤」
- **界面风格**：直角（Windows 10 那种直棱直角 + 扁平化，默认）/ 圆润
- 另外可调：**界面密度**（舒适 / 紧凑）、**字号**（小 / 标准 / 大 / 特大）、
  **毛玻璃效果**（低性能设备可关掉）

入口：右上角 ⚙ / `Ctrl + ,` / 命令面板搜「主题色」

实现：

- 令牌定义 `src/styles/themes.css`
- 状态与持久化 `src/store/settings.ts`
- 面板 UI `src/components/overlays/SettingsPanel.tsx`
- 首屏防闪 `index.html` 里的内联脚本

### 自定义背景图 + 自动取主题色

在设置面板的「背景图片」里选一张本地图片即可：

- 图片**只存在本机浏览器**（IndexedDB），不会上传到服务器
- 打开「启用背景图」后整个界面变成**亚克力质感**：面板半透明，图片透出来
- 三个可调参数：**图片模糊**、**暗化/白色蒙版**（保证文字可读）、**面板不透明度**
- 打开「自动从背景图提取主题色」后，换图时会自动把主题色调成图片的主色；
  也可以随时点主题色那一行的**取色器图标**手动重新提取

实现：

- 取色算法 `src/lib/imageColor.ts`（加权色相直方图，不是取平均色）
- 图片存储 `src/services/assets.ts`（IndexedDB 的 `assets` 表）
- 状态 `src/store/background.ts`
- 渲染 `src/components/layout/BackgroundLayer.tsx`

## 2. 命令面板（⌘K 式）

`Ctrl/⌘ + K` 打开，一个输入框搜所有东西：

- **会话** —— 直接跳转并加载历史
- **身份** —— 一键切换当前身份
- **外观** —— 逐条列出 8 套主题色、暗色/亮色模式
- **操作** —— 设置、重连、清空记录、导出、管理会话/身份

支持 ↑↓ 选择、Enter 执行、Esc 关闭；结果按「匹配位置 + 分组」排序。

实现：`src/components/overlays/CommandPalette.tsx`

---

## 3. 会话内搜索

`Ctrl/⌘ + F` 打开搜索条，在当前会话的**已渲染内容**上做高亮：

- 实时显示 `当前项 / 总匹配数`
- Enter 下一个、Shift+Enter 上一个
- 当前项有单独的强调色，并会自动滚动到可见位置

实现要点：`lib/searchHighlight.ts` 是在**文本节点**上做替换，而不是对 HTML 字符串
做正则替换 —— 后者会把标签属性里的文字也高亮掉，甚至破坏 HTML 结构。

## 4. 消息能力

| 能力 | 说明 |
| --- | --- |
| Markdown | GFM 全量；表格、引用、列表、任务列表都支持 |
| 代码高亮 | 语言标签 + 悬浮「复制」按钮；按需注册 27 种常用语言 |
| 图片 | 多图网格排列，点击开灯箱 |
| @提及 | 以标签形式展示，能解析出用户 ID 对应的名字 |
| 回复引用 | 气泡内显示被引用消息的摘要，点击跳转并高亮闪烁 |
| 时间 | 按天分组，超 5 分钟的间隔会重新显示头像与时间 |

实现：`src/components/chat/MessageItem.tsx`、`Markdown.tsx`

### 自己发的消息为什么不会重复

发送采用「乐观渲染 + 回显对账」：

1. 点发送后立刻在本机插入一条气泡，右下角显示「发送中…」
2. 这条消息会带一个随机的 `echo` 标记发给服务端
3. 服务端把它广播回来时会带上同一个 `echo`
4. 前端认出「这条广播就是我刚发的那条」，**原地替换**掉本地占位气泡，
   「发送中…」随之消失

所以界面上永远只有一条，既不用等一个来回才看到自己的消息，也不会重复。
如果服务端没有实现 `echo`，前端会退化为按内容匹配本地气泡；
再退一步（服务端连广播都不回）也会在 12 秒后把状态拨回「已发送」。
详见 [ARCHITECTURE.md](ARCHITECTURE.md)。

### 引用了一条本地没有的消息

气泡里的引用卡片会先查本地历史；查不到就调用 `GET /message/{message_id}`
去后端取一次，取不到才显示「原消息已删除」。
实现：`store/chat.ts` 的 `ensureQuote()`、`services/client.ts` 的 `fetchMessage()`。

### 消息右键菜单 / 悬浮操作

鼠标悬停气泡右侧会出现快捷按钮（回复、复制、@、更多）；右键任意消息打开菜单：

- 回复
- @ 该发送者
- 复制文本
- 查看图片（有图时）
- 删除这条消息（仅自己发的）

实现：`MessageContextMenu.tsx`、`MessageItem.tsx`

## 5. 输入框（Composer）

- **自动增高**，最高 220px
- **发送方式可切换**：`Enter` 发送 或 `Ctrl/⌘ + Enter` 发送（Shift+Enter 换行）
  - 中文输入法组字过程中按 Enter 不会误发（判断 `isComposing`）
- **草稿按会话保存**：切走再切回来，没发出去的内容还在
- **图片**：点击上传 / 拖拽到输入区 / 直接粘贴剪贴板截图
- **@提及自动补全**：输入 `@` 弹出候选列表，↑↓ 选择、Enter 确认
- **表情面板**：内置 30 个常用表情
- **@BOT 开关**：对应协议里 `at: [""]` 的约定

实现：`src/components/chat/Composer.tsx`、`ComposerStatus.tsx`、`AttachmentTray.tsx`

## 7. 未读与通知

- 每个会话有未读角标，浏览器标题栏显示 `(总数) clovers 终端`
- 其他会话来消息时插入一条「以下为新消息」分隔线
- 可选**桌面通知**（首次开启会申请权限；权限被浏览器撤销后会自动把开关关掉）
- 可选**新消息提示音**（WebAudio 生成的短提示音，不依赖音频文件）

实现：`src/store/chat.ts`（`ingest()`）、`src/store/bridge.ts`（`actions.setNotify`）

## 8. 会话与身份管理

**会话管理**：新建、重命名、改 ID、改头像（可上传）、删除（连同本地记录）。

> 改会话 ID 时前端会把本地历史一起迁移到新 ID 下，否则切过去就是空的。

**身份管理**：新建、改名称/ID/头像/权限、切换当前身份、清理其他身份。

权限分四档：超级用户 / 群主 / 管理员 / 成员，会以彩色标签显示在消息气泡上方。

实现：`overlays/GroupDialog.tsx`、`overlays/UserDialog.tsx`

## 10. 连接状态

侧栏顶部与会话标题都会显示连接状态（连接中 / 已连接 / 已断开）：

- 断线后指数退避自动重连（0.5s → 1s → 2s …，上限 15s）
- 断开期间发送的消息进入队列，连接恢复后自动补发（此时气泡显示「发送失败」，
  但消息已在队列里，重连后会真正发出去）
- 可以点状态标签手动立即重连

实现：`src/services/client.ts`、`src/store/connection.ts`

## 12. 旧数据迁移

从旧版本升级上来的用户，第一次打开某个会话时：

1. 从 IndexedDB 的 `histories` 表读出旧版 HTML 快照
2. 用 `DOMParser` 解析，把每条 `.message` 还原成结构化消息
   （包括发送者、@提及、回复关系、图片；正文会尽量还原成 Markdown）
3. 写入新版 `messages` 表，然后删掉旧快照
4. 弹出 Toast 告知迁移了多少条

如果某条记录解析不出内容会被跳过，**不会**因为一条坏数据导致整个会话打不开。

实现：`src/services/legacy.ts` + `history.ts` 的 `migrateLegacy()`

## 13. 移动端适配

- 900px 以下侧栏变成抽屉，由顶栏左侧的汉堡按钮唤出，点遮罩关闭
- 顶栏在窄屏只保留搜索与「更多」，其余功能都收进菜单与命令面板
- 发送按钮窄屏只显示图标，把宽度让给输入框
- 消息气泡宽度自适应，代码块在气泡内部横向滚动，不会把页面顶宽

## 附：Toast 提示

所有异步操作的结果（上传失败、导出完成、复制成功、记录清空、连接断开…）
都通过右下角的 Toast 反馈，错误类会多停留一会儿。
代码里用 `import { toast } from '@/store/ui'` 直接调用即可，不需要放在组件里。
